# Express MySQL Auth

A RESTful authentication API built with Express.js for secure user authentication.
Supports registration, login, email verification, and JWT-based session management.
Uses access and refresh tokens to maintain authenticated sessions across requests.
Designed with a clean, modular structure for easy maintenance and future expansion.

This project includes interactive API documentation powered by Swagger (OpenAPI 3.0).

You can find them at
http://localhost:1000/api/v1/api-docs
